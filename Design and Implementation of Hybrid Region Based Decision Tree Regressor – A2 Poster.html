01. Problem Statement

Traditional Decision Tree Regressors (DTRs) are interpretable and divide the feature space into rectilinear regions, but they produce constant predictions within each leaf, limiting their ability to capture complex local non-linear patterns.
Neural Networks can learn such non-linear relationships but lack the region-based interpretability of decision trees.
Therefore, there is a need for a hybrid approach that combines the interpretability and rectilinear region structure of Decision Trees with the local non-linear learning capability of Neural Networks.

02. Objective

Develop a hybrid Decision Tree–Neural Network regressor.
Replace constant leaf predictions with leaf-specific neural networks.
Optimize models using Optuna hyperparameter tuning.
Evaluate performance on 12 regression datasets.
Improve R² and Adjusted R² while preserving interpretability.

03. Core Architecture

1. Partition: the DTR divides the feature space into leaves.
2. Localize: each leaf gets its own NN, trained only on that leaf's data.
3. Predict: a new point is routed to its leaf; that leaf's NN gives the output.

05. Evaluation Metric Used

R² measures goodness of fit, but never decreases when features are added, even useless ones.

Adj R² = 1 − (1 − R²)(n − 1)/(n − p − 1)

Adjusted R² penalizes unnecessary complexity (n = data points, p = features), so it is more reliable.

07. Implementation: Python Library

Packaged on PyPI as hybrid-dt-nn so anyone can use it in a few lines:

!pip install hybrid-dt-nn
from hybrid_dt_nn import HybridTreeRegressor
model = HybridTreeRegressor(
  dt_max_depth=3, dt_min_samples_leaf=1000,
  nn_min_samples=50, use_hpo=True,
  hpo_trials=30)
model.fit(X_train, y_train)
preds = model.predict(X_test)
model.score(X_test, y_test)

Stack: Python · Scikit-learn (tree) · TensorFlow/Keras (NNs) · Optuna (HPO) · NumPy · Git/GitHub · Colab/VS Code. Leaves with enough data get an NN; hyperparameter optimization (HPO) is optional.

08. Conclusion

Leaf-level NNs capture local patterns missed by traditional DTRs.
Adjusted R² improved across all 12 datasets, by up to +0.46.
A minimum leaf size of 1000 improves NN training stability.
Released as the installable hybrid-dt-nn PyPI library.
Future work: compare with model trees and ensembles, use adaptive leaf models, reduce training cost, and extend to classification and time series.
